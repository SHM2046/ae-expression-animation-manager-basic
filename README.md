# AE 表达式动画管理器（基础版）

面向 **After Effects 2022+** 的 CEP 停靠面板。它用表达式为 2D 图层叠加固定 2 秒（25fps / 50 帧）的位移、旋转、缩放循环，并集中管理参数与偏移。

## 一键安装（Windows）

双击 [一键安装AE动画管理器.cmd](./%E4%B8%80%E9%94%AE%E5%AE%89%E8%A3%85AE%E5%8A%A8%E7%94%BB%E7%AE%A1%E7%90%86%E5%99%A8.cmd) 即可。安装器会：

- 安装到当前 Windows 用户的 CEP 扩展目录；
- 将同名旧版本移至带时间戳的备份目录；
- 开启当前用户的 CEP 调试模式，以加载此未签名开发插件；
- 提示重启 After Effects。

首次安装后，在 AE 中通过 `窗口 > 扩展 > AE 动画管理器（基础版）` 打开面板。

基础版与 Agent 高阶版使用不同的 CEP 标识和安装目录，可以同时安装：日常稳定工作请打开“基础版”；Agent 测试请在 AE 2024 打开高阶版。

## GitHub 更新

面板启动后会从公开 GitHub 更新清单检查基础版更新。点击“检查更新”，发现版本后点击“下载并退出后安装”；保存工程并**完全退出 AE**，安装器会自动更新基础版。此流程不会覆盖 Agent 高阶版。

> 如需安装但不启用 CEP 调试模式，可右键以 PowerShell 运行 `install.ps1 -DisableDebugMode`。未签名插件通常需要调试模式才能加载。

## 手动安装

请直接按照 [手动安装说明.md](./%E6%89%8B%E5%8A%A8%E5%AE%89%E8%A3%85%E8%AF%B4%E6%98%8E.md) 操作。关键是将 `CSXS`、`client`、`host` 三个文件夹复制到 `%APPDATA%\\Adobe\\CEP\\extensions\\AEExpressionAnimationManager` 内，不能多一层目录。

## 使用

1. 在活动合成选择一个或多个 **2D** 图层，点击“添加动画”。
2. 在图层卡片点击“添加位移 / 旋转 / 缩放”，调节幅度和独立偏移。
3. 关闭开关会暂停而不删除设置；`×` 彻底移除单项控制，“清理”移除该图层所有本插件控制。
4. 先筛选一项属性，再点击“随机偏移”或“平均偏移”。平均偏移按合成层级、再按 AE 图层序号分布在 0–49 帧。
5. 直接编辑缩略图下方的图层名称并按 Enter（或点击别处），名称会同步写回 AE 时间轴；镜像图层会使用 `镜像_原名称` 命名。
6. 图层卡片的“存为全局”会把该图层当前已有的动画控制保存为一个新的全局关联；随后可从“全局”下拉列表将它应用到其他图层。
7. 默认只自动跟随已经使用过本插件的合成。可关闭“自动跟随已管理合成”，在大型工程中避免切换普通合成时触发面板读取；合成下拉列表也只显示已管理合成。

## 约束

- 仅支持 2D、未分离 Position 维度的图层；3D/分离维度图层会被跳过。
- 原有关键帧会保留并作为表达式基值；已有非本插件表达式不会被覆盖。
- 对已有锚点或 Position 关键帧的图层，锚点编辑会拒绝执行，以避免改变原动画。
- 缩略图直接支持 PNG/JPEG/GIF/BMP 素材；其他类型使用图层类别图标。这是 CEP 和 AE 脚本 API 不提供统一图层渲染缩略图的兼容降级。
- 为了降低添加、镜像与映射时的卡顿，以上操作不再同步渲染缩略图；可使用“刷新缩略图”或卡片缩略图右下角的刷新按钮按需生成。

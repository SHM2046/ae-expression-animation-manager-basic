# AE 表达式动画管理器：开发交接

更新日期：2026-08-20（香港时间）  
目标宿主：After Effects 2022+ / CEP / Windows

## 当前可用状态

已实现：

- CEP 停靠面板，按活动合成显示已登记的 2D 图层；可锁定合成、递归展示子预合成。
- 位移、旋转、缩放三种表达式控制；固定为 2 秒 / 25fps / 50 帧循环。
- 每项有启用、幅度、独立 0–49 帧偏移；可筛选属性并随机/平均偏移。
- 保留已有关键帧；遇到非本插件表达式会拒绝覆盖。
- 旋转锚点在图层预览上点击或拖拽，且静态 Position/Anchor Point 会做位置补偿。
- 图层卡片现已改为：左侧缩略图，右侧横向三列（位移 / 旋转 / 缩放），降低纵向占用。
- 已提供一键安装、手动安装、CEP 调试模式注册表文件。
- 图层名称可直接在面板改写，并同步回 AE 时间轴；镜像副本命名为 `镜像_原图层名`。
- 可将当前图层的既有动画控制“存为全局关联”，再从全局下拉列表应用到其他图层。
- 合成下拉列表仅保留已使用本插件的合成；默认自动跟随也仅响应已管理合成，可由面板开关关闭。
- 添加动画、镜像与动画映射不再同步生成缩略图，改为按需刷新，避免大型工程的明显卡顿。

## 项目结构与职责

| 路径 | 职责 |
| --- | --- |
| `CSXS/manifest.xml` | CEP 面板注册；最低 AE 宿主为 22.0。 |
| `client/index.html` | 面板 HTML 模板。 |
| `client/panel.css` | 深色紧凑面板与横向三列布局。 |
| `client/panel.js` | UI 状态、`evalScript` 桥接、参数控件、缩略图锚点交互。 |
| `host/animation-manager.jsx` | AE 图层扫描、Effect Controls、表达式、批量偏移、锚点补偿、缩略图缓存。 |
| `tests/expression-contract.test.mjs` | Node 静态契约测试。 |

## 关键实现约定

- 本插件所有 Effect Controls 前缀为 `AEMGR`；`AEMGR Registered` 用于在工程重开后识别已管理图层。
- 写入的表达式以 `// AEMGR:v1:<property>` 开头，只清理带该标记的表达式。
- 位移在基础位置的正负幅度间摆动；旋转和缩放的“幅度”是总范围，例如 20 表示 -10 到 +10。
- “关闭”只将 Enabled 滑块置零；`×` 才移除对应表达式和控件；“清理”移除该图层所有本插件控件。
- `client` 通过 `__adobe_cep__.evalScript` 调用宿主函数；参数以 JSON 字符串传入。

## 缩略图与锚点

1. PNG/JPEG/GIF/BMP 源素材直接以文件路径加载到 CEP 面板。
2. PSD、视频、预合成等不可直接被 Chromium 解码的素材，`host/animation-manager.jsx` 会尝试创建 160×90 临时合成并输出 PNG 缓存至 `%TEMP%\AEMGR_Thumbnails`。
3. 缩略图生成时会临时禁用渲染队列中已有项目的 `render` 标志，并在完成或失败后还原；不能在 AE 正在渲染队列时操作本面板。
4. 当前锚点编辑只支持 Anchor Point 和 Position 都没有关键帧的 2D 图层；否则会提示并跳过，以免破坏原动画。

## 必须在 AE 中复核的项目

这些无法在没有 AE 的环境中自动验证：

1. 重启 AE 后，横向三列是否在你的屏幕宽度下符合预期；需要时继续压缩单列控件高度。
2. 用 PNG、PSD、视频、预合成各测试一层，确认缩略图缓存能生成。若 PNG 序列输出模板在家中 AE 的语言环境里不存在，需在 `renderThumbnail` 中改为该环境的 PNG 输出模块模板名。
3. 在真实素材缩略图上拖动旋转锚点，确认合成画面没有跳动。
4. 对含原关键帧、外部表达式、3D 图层、分离维度 Position 图层各做一次回归。

## 已知限制

- 仅支持 2D 且未分离 Position 维度的图层。
- 真实缩略图依赖 AE Render Queue 的 PNG 输出模板；生成失败会退回图层类型图标，并在临时目录留下 `unavailable.txt` 防止重复渲染。
- 缩放“基础”控制当前统一改写 X/Y；不支持非等比缩放的独立基础值编辑。
- 没有建立 Git 提交历史，也未做签名/打包发布。

## 推荐的下一步开发顺序

1. 在家中先做上面的 AE 冒烟测试，记录缩略图生成是否正常，以及普通（未管理）合成切换是否不再触发面板加载。
2. 根据你的面板实际宽度微调三列最小宽度、缩略图尺寸与滑杆密度。
3. 为缩放增加独立 X/Y 基础值；为 3D 与分离维度图层设计兼容策略。
4. 增加“所有图层 / 当前选中图层”批量操作范围和参数预设。
5. 建立 Git 仓库、记录变更，并在完成后签名或制作正式安装包。

## 在家部署与同步

- 开发源码目录可以放在任意位置。
- CEP 安装目录固定为：`%APPDATA%\Adobe\CEP\extensions\AEExpressionAnimationManager`。
- 首次安装可双击 `一键安装AE动画管理器.cmd`；首次失败时按 `手动安装说明.md` 复制 `CSXS`、`client`、`host` 三个目录。
- 每次修改源码后运行：`powershell -ExecutionPolicy Bypass -File .\scripts\sync-installed.ps1`。
- 之后必须完全退出并重开 AE；仅关闭面板通常不足以重新加载 `host` 脚本。
